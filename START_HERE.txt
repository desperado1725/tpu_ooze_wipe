TPU OOZE WIPE — WINDOWS SETUP

WHAT IT DOES
Before switching away from TPU, the H2D nozzle makes 10 zigzag wipes over
its existing prime tower, taking approximately 10 seconds. The nozzle target
is set to 200 C as wiping begins. It cools while wiping; it does not wait to
reach 200 C. The normal print sequence then continues.

BEFORE YOU START
Use an H2D dual-nozzle project with TPU identified as TPU in its filament
profile, Print sequence set to By layer, and a printed prime tower. This
script was developed with TPU on the right/nozzle 2 and PLA on the left/nozzle 1.

1. EXTRACT THE FILES
Download the ZIP and choose Extract All. Keep the extracted files in a
permanent folder, for example:
  C:\BambuScripts\tpu_ooze_wipe
The folder contains:
  tpu_ooze_wipe.py    — the script Bambu Studio runs
  setup_command.py   — generates your setup command
  START_HERE.txt     — this guide
  README.md          — overview and requirements

2. INSTALL PYTHON IF NEEDED
Download Python from:
  https://www.python.org/downloads/windows/
Follow the installer prompts to install a Python runtime. Python 3.10 or
newer is required. No additional Python packages are needed.

Open a new Windows Terminal or Command Prompt and enter:
  python --version
If that command is not found, try:
  py --version
Use whichever command works in the next step. If neither works, finish
installing Python and reopen Terminal. Installation help:
  https://docs.python.org/3/using/windows.html

3. GENERATE YOUR COMMAND
Enter this in Terminal, adjusting the folder to match where you extracted it:
  python "C:\BambuScripts\tpu_ooze_wipe\setup_command.py"
Use py instead of python if that was the command that worked above.

The setup program creates BAMBU_COMMAND.txt beside the script. Open that
file in Notepad and copy the entire line. It contains two quoted paths:
the Python executable and tpu_ooze_wipe.py. Keep both sets of quotes.

4. ADD THE COMMAND TO BAMBU STUDIO
Open your project in Prepare. Enable Advanced mode in the Process settings.
Under Others, find Post-processing Scripts and paste the generated command.
You can also find the field using the settings search.

Bambu Studio supplies the G-code filename automatically. Do not add one.
This command belongs in Post-processing Scripts, not in a machine G-code field.
If other scripts are present, preserve their entries; separate commands with
semicolons. Add this script only once.

Save a separate process preset, such as H2D TPU ooze wipe. Keep the script
folder in place. If you move it or change Python installations, rerun the
setup program and replace the command in Studio.

5. SLICE AND CHECK
Re-slice your project and let processing finish. Resolve any reported error
before printing. Check the processed preview and start with a small supervised
print to test the 200 C cooldown with your filament.

Wipes happen when switching away from TPU, not on every layer. The very small
extrusion amount can make them difficult to see in the preview. If needed,
export and reopen the processed G-code to inspect it. In a plain G-code text
export, search for TPU_PRIME_ZIGZAG_BEGIN and comments wipe 1 through wipe 10.

TURNING IT OFF
Remove the command from Post-processing Scripts and re-slice the project.
Previously exported G-code still contains the wipes.

COMMON PROBLEMS
Win32 error 193 / Failed starting script:
  Use the entire generated command, including the Python executable path.
No module named tpu_ooze_wipe:
  Keep setup_command.py and tpu_ooze_wipe.py in the same folder.
Python or file not found:
  Check the folder paths and rerun setup_command.py.
Cannot establish complete planar prime-tower footprint:
  Prime-tower extrusion must use planar, straight-line moves. Arc fitting
  and scarf seams elsewhere in the model may remain enabled.
Re-slice original project:
  Slice the model project again instead of reprocessing an earlier export.
No wipes visible:
  Check that both nozzles and TPU are used, and that the prime tower is
  printed at the outgoing TPU layer height. A wipe is skipped if no suitable
  tower exists at that height.

This setup guide is for Windows. Other systems need their own Python path.
